# Next.js Clear Week verification — 2026-10-21

## Regression fixes discovered while building

- Default every-N interval is initialized to 2 rather than displaying a value absent from the payload.
- Restored edited drafts retain their original revision, preventing a resumed draft from silently overwriting a later edit.
- A 409 refetches authoritative queries before offering conflict recovery; draft fields remain intact.
- Historical detail reads the finalized group name, not the group's current name.

## Remaining milestones

Drag/resize/external drop/Undo, optional account-wide Pomodoro, aggregate period analytics/comparisons, and final operational acceptance are not claimed complete here. No public deployment has been performed.

## Fresh review and fixes

A fresh reviewer identified four important issues. Each was corrected with regression evidence: late completion from an unmounted editor cannot delete/close another draft; owned successful API responses carry `X-Account-ID` and are rejected if they do not match the query account; settings offer explicit reapply/discard conflict recovery; group/settings drafts and uncertain command payloads/keys survive session expiry under owner-specific storage keys. Focus/reconnect validates identity before query invalidation, and aborted queries are not treated as network failures.

Review minors deferred: day/month calendar cells do not yet embed their own daily progress (the independent Progress view does); weekly recurrence summary does not yet spell out the weekday. These remain UI refinements alongside Task 7.
