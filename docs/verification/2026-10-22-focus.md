# Optional Pomodoro verification

The timer is account-wide and independent of task status. Start free focus or choose Focus on this task. Defaults are 25/5/15 minutes; every fourth full focus session suggests a long break. Settings apply to subsequent sessions, while active targets remain unchanged. Starting the next session always requires a user action.

## Persistence and concurrency

An account lock and partial unique index allow one running/paused session. Mutation receipts make retries stable. Persisted running intervals exclude pauses and breaks from focus time. The server caps elapsed time at the original target, settles expired sessions before claiming a new slot, and records one Pomodoro only for a fully elapsed focus session. Early end records actual focus time. Soft-deleted task references and title labels remain available in session history.

The UI extrapolates display time from acknowledged elapsed time using a monotonic browser clock. Reconnection refreshes authoritative state; offline controls cannot change it. Uncertain timer commands keep their exact payload/key and can be retried. Sound is unlocked through a user gesture; browser notification permission is requested explicitly. Denial does not block normal usage.
